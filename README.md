# Pracownia-Programowania
Repozytorium dla wrzucania kodu z lekcji pracowni programowania dla celow powtorzenia klasy 4B


Aby pobrac repozytorium na swoje urzadzenie nalezy przejsc do wybranego folderu a nastepnie wkleic ta komende `git clone https://github.com/kanoneq/Pracownia-Programowania.git`

Aby uruchomic jakikolwiek plik w terminalu trzeba wpisac `python <nazwa_pliku.py>`* (zwracajac uwage na to gdzie jestesmy w terminalu)
*ewentualnie python3 ale to zaleznie od tego jaka ma sie zainstalowana wersje
